# SelfXpress — loja online (v2)

Loja de tecnologia, eletrodomésticos e gadgets para crianças em Maputo e Matola, feita só com **HTML, CSS e JavaScript**. O hero original (carrossel de 3 slides, barra de redes sociais e faixa promocional) foi mantido tal como era, agora sem Bootstrap. O resto do site segue a mesma linguagem: fundo preto, Poppins e Quicksand, subtítulos em Emblema com gradiente, botões verde→azul.

## Páginas
| Página | Conteúdo |
|---|---|
| `index.html` | Hero original, categorias, mais vendidos, setup com pontos clicáveis, oferta da semana com contagem decrescente, como funciona, banner, testemunhos, contacto |
| `loja.html` | Catálogo com categorias, pesquisa, filtros (preço, promoções, stock, recondicionados) e ordenação |
| `produto.html#<id>` | Página de produto: quantidade, entrega por zona, especificações, produtos relacionados |
| `sobre.html` | História, números, compromissos, zonas de entrega, valores, perguntas frequentes |

O carrinho fica guardado no navegador e a encomenda é enviada como mensagem pronta para o WhatsApp da loja (pagamento na entrega: M-Pesa, e-Mola, cartão ou numerário).
